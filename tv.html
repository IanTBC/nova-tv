Nova TV on your TV.

The same app as the Mac, built for the remote: Live TV with the guide, Movies, TV Shows, subtitles, quality, profiles and Top 10. Install it in about 5 minutes with the free Downloader app.

Type this in Downloaderiantbc.github.io/nova-tv/tv.apk

  1. Install Downloader

    On the TV, go to search, type Downloader and install the free app Downloader by AFTVnews (orange icon).

  2. Turn on Developer options (one time)

    Open Settings → System → About, scroll to Android TV OS build and press OK on it 7 times until it says "You are now a developer".

    Google TV only lets you install apps from outside the Play Store after this. It doesn't change anything else.

  3. Allow Downloader to install apps

    Go to Settings → Apps → Security & restrictions → Unknown sources and switch Downloader on.

    On some TVs it's under Settings → Device Preferences → Security & restrictions.

  4. Download Nova TV

    Open Downloader, select the address box, type iantbc.github.io/nova-tv/tv.apk and press Go. When it finishes, press Install, then Open.

    Downloader may then ask to delete the file — press Delete, it's not needed anymore.

  5. Log in

    Enter your Server URL, Username and Password (or your M3U link), exactly like on the Mac. Nova TV now sits in your apps row — hold OK on it and choose Move to pin it to the front.

  6. Updates are automatic

    Design and feature updates arrive by themselves; you'll see Restart now. If a bigger update needs a reinstall, Nova TV shows Install — the first time, the TV asks you to allow Nova TV to install apps: switch it on, press Back and choose Install again.
